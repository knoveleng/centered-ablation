Centered Ablation: Why Last-Layer Directional Ablation Under-Fires or Collapses, and a Closed-Form Fix

Quy-Anh Dang · Chris Ngo

Knovel Engineering Lab, Singapore

Paper Code BibTeX
TL;DR

At the last layer, directional ablation is exactly a logit bias scaled by a cosine with the hidden state. Hidden states share a large common mode far from the origin, so the standard direction fires on benign text and under-fires on its target. Centered Ablation projects the common mode out of the direction: closed form, no new hyperparameter.

The problem

Three ways directional ablation fails

The standard way to switch off a behaviour such as refusal is directional ablation: take the difference of mean activations on harmful and benign prompts (DIM) and remove each hidden state's component along it. On some models it barely fires; on others it breaks the text. All outputs below are real (greedy, strength \(s=1\)).

The literature treats these as model-specific quirks. They are one mechanism.

The mechanism

The edit is a logit bias with a gate, and the gate is measured from the wrong place

We look at the one place where ablation has a closed form: the residual stream after the last decoder block, which feeds only the final RMSNorm and the unembedding \(W_U\). There, removing a direction \(u\) from a hidden state \(h\) changes the logits by exactly

$$\Delta\,\text{logits} \;\propto\; -\,s\;\underbrace{\cos\angle(h,u)}_{\textbf{gate}}\;\underbrace{W_U\,G\,u}_{\textbf{footprint}}$$
Footprint
A fixed vector over the vocabulary: which tokens the edit pushes down.
Gate
The cosine between the state and the direction: how hard the edit fires at this token. A state is untouched only if its gate is zero.
Common mode
Last-layer states do not scatter around the origin. They cluster along one shared direction \(\hat\mu_-\), far from it.
Overlap \(\omega\)
How much the direction points along the common mode, \(\omega=|u^\top\hat\mu_-|\). The mean gate on benign text is roughly \(\omega\), whatever the strength.

A cosine is measured from the origin, so a direction that overlaps the common mode has a gate floor on every benign state. That floor causes the collateral, and once the bias exceeds the spread of the model's own logits, the collapse. The same overlap wastes part of the unit direction, so it under-fires on its target. The fix

Centered Ablation: measure the gate from the benign class

Remove the common mode from the direction before ablating:

$$u_{\mathrm{CA}} \;=\; \mathrm{unit}\!\big((I-\hat\mu_-\hat\mu_-^\top)\,u_{\mathrm{DIM}}\big)$$ $$h \;\leftarrow\; h - s\,(h^\top u_{\mathrm{CA}})\,u_{\mathrm{CA}}$$
  • No floor. \(u_{\mathrm{CA}}\) has zero overlap with the common mode, so benign states get a gate near zero.
  • Signal kept. It keeps all of the class separation except the share that pointed along the common mode: a factor \(\sqrt{1-\omega^2}\).
  • Closed form. Two sample means, one projection. No optimisation, no hyperparameter beyond the strength \(s\). Negative \(s\) amplifies refusal instead.

Prior work (ACE) centres the gate differently, by subtracting the benign coefficient while keeping \(u_{\mathrm{DIM}}\). We call it DIM+offset and derive the difference: it fires harder by \(1/\sqrt{1-\omega^2}\), but keeps the common mode's variance on benign states, so it rewrites more benign text when \(\omega\) is large.

Minimal sketch · PyTorch + transformers 
import torch

def centered_direction(H_pos, H_neg):
    # last-layer states, last prompt token: [n, d]
    u = H_pos.mean(0) - H_neg.mean(0)
    u = u / u.norm()  # u_DIM
    rms = H_neg.pow(2).mean(-1, keepdim=True).sqrt()
    mu = (H_neg / rms).mean(0)
    mu = mu / mu.norm()  # common mode
    u = u - (u @ mu) * mu  # project out
    return u / u.norm()  # u_CA

def ablate_last_layer(model, u, s=1.0):
    # input of the final norm = last residual stream
    def hook(module, args):
        h = args[0]
        v = u.to(h.device, h.dtype)
        return (h - s * (h @ v)[..., None] * v,)
    norm = model.model.norm
    return norm.register_forward_pre_hook(hook)

The full pipeline (calibration draws, judges, diagnostics, vLLM serving) is in the repository.

Does it work?

Each failure is repaired on the models that show it, and little changes elsewhere

8 instruction-tuned models (Qwen2.5, Qwen3, Llama-3, Gemma-2), mean over 6 calibration draws, HarmBench (240 harmful requests) and 100 held-out benign Alpaca prompts. Models are ordered by their overlap \(\omega\). Hover a row for exact values.

+29 / +46 attack-success points on the two models where DIM under-fires (Llama-3.1-8B, Llama-3.2-3B)
50% → 1% collapse on Gemma-2-9B, at the same fluent attack success
12–40 more benign answers preserved on the four high-\(\omega\) models
≤ 0.7 MMLU points moved, for every model and direction

Attack success is fluent-only: a degenerate output counts as a failure, whatever a judge says (see why). A benign answer counts as rewritten when its string similarity to the unsteered answer is below 0.5. CA is not a stronger attack than DIM+offset; it is the route that keeps benign behaviour intact.

Know before you run

Two numbers from cached activations predict two different benefits

Both are computed from last-layer states and the model's \(W_U, G\), without generating text or calling a judge. The analysis was built on 3 pilot models; for the 5 others, the diagnostics and a predicted regime were recorded before they generated any text.

pilot model added later, predicted before generation

A third number, the collapse index \(\beta^+\) (bias size over the logit spread), marks degeneration: the only 6 of 144 runs with \(\beta^+>1\) are Gemma-2-9B under DIM, and they are the ones that collapse. The closed form itself predicts the served model's steered first token on 96.1% of prompts.

Measure it right

Two standard safety judges score collapsed text in opposite directions

Judged harmful, Gemma-2-9B under DIM ablation (240 outputs)

Half of these outputs are “Here Here Here…”. On them, the HarmBench classifier says harmful 1.7% of the time and Llama-Guard-3-8B 98.3%. One judge makes collapse look like a perfect defence, the other like a perfect attack. On fluent outputs they agree.

Without a fluency filter, this alone fabricates a 46-point difference between DIM and CA under Llama-Guard. With it, the difference vanishes.

Multiple-choice benchmarks miss the cost too: interventions that move MMLU by at most 0.7 points rewrite up to 88% of free-form benign answers.

Recommendation. Report fluent-only success together with a collapse rate and a free-form faithfulness measure.

Scope

Where last-layer ablation stops

  • Few-token behaviours only. It controls refusal, which is decided at a few tokens. On emotional tone, which is spread across a text, CA removes 60% of the emotion's words at \(s=3\) but lowers the judged emotion by only 19 points.
  • Refusal has a second stage. On Gemma-2-9B, CA removes the refusal onset, but about half the continuations then deflect (“Here's the thing: X is harmful…”). No single direction carries this stage.
  • One site, one operator. The closed form holds at the last residual stream, for rank-1 ablation, under greedy decoding.
  • Small \(n\). The diagnostic laws rest on 8 models; only one crosses the collapse threshold.

Responsible use

Why publish this

This work analyses an intervention that can remove a model's refusal behaviour. Refusal removal on open-weight models is already public, and CA is not a stronger attack than existing ones. The same analysis shows how to amplify refusal against jailbreaks: with negative strength, CA stays fluent where DIM collapses, cutting jailbreak success on Gemma-2-9B to 14.1%. We expect the main effect to be better evaluation practice: fluency-filtered judging, free-form faithfulness checks, and diagnostics that flag unreliable interventions before deployment.
